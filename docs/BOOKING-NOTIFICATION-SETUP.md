# 예약 확정 알림 → 일정 자동 등록

네이버 지도에서 식당·미용실을 예약하면 폰에 "예약이 확정되었습니다" 알림이 온다.
그 알림을 서버로 보내면 **일정이 자동으로 만들어진다.**

카드 알림([CARD-NOTIFICATION-SETUP.md](./CARD-NOTIFICATION-SETUP.md))과 같은 구조이고,
**비밀키도 같은 것(`CARD_NOTIFY_SECRET`)을 쓴다** — 폰에 값을 하나만 넣으면 되도록.

---

## 1. 폰 설정 (MacroDroid)

권한은 카드 알림과 같다. 이미 카드 알림을 쓰고 있으면 **매크로만 하나 더 만들면 된다.**

**발동** — `기기 이벤트 → 알림 → 알림 수신됨`

| 애플리케이션 | 포함하는 텍스트 |
|---|---|
| 네이버 지도 | `예약` |
| 레슨북 | `타석` |

> 단어 조건 없이 앱 전체를 보내면 광고 알림까지 넘어간다. 반드시 조건을 건다.

**동작** — `웹 접속 → HTTP 요청`

| 항목 | 값 |
|---|---|
| 요청 방식 | `POST` |
| URL | `https://<앱주소>/api/tasks/notify?secret=<비밀키>&member=성진` |
| 콘텐츠 유형 | `text/plain` |
| 본문 | `[notification]` (매직 텍스트 → "알림 텍스트") |

**`member=` 는 폰마다 다르게 넣는다.** 예약 알림에는 누구 것인지 정보가 없어서,
"어느 폰이 보냈는지"로 예약자를 정한다. 이름은 구성원 이름과 정확히 같아야 한다.

---

## 2. 지원하는 알림 형식

| 규칙 | 예시 | 결과 |
|---|---|---|
| `naver-booking-v1` | `네이버지도 머바르지 죽전2호점 8.22(토) 오후 5:00 예약이 확정되었습니다.` | 8/22 17:00~18:00 "머바르지 죽전2호점 예약" |
| `lessonbook-golf-v1` | `금일 13:51~14:50까지 3번 타석예약 됐습니다.` | 오늘 13:51~14:50 "골프 연습 (3번 타석)" |
| `generic-timerange-v1` | `... 8/10 14:00~15:00 예약이 완료되었습니다` | 8/10 14:00~15:00 "예약" |

**날짜** `8.22` · `8/22` · `8월 22일` · `2026.8.22` · `내일` · `모레` · (없으면 알림 온 날)
**시각** `오후 5:00` · `17:00` · `오후 5시` · `오후 5시 30분` · `오후 5:00~7:00`

> **종료 시각이 없으면 1시간짜리 일정**으로 잡는다. 네이버는 시작 시각만 주기 때문이다.
> 실제와 다르면 일정을 열어 고치면 된다.

**등록되지 않는 것**
- `특가` `할인` `이벤트` `쿠폰` `지금 예약` `예약하세요` `오픈` → 광고로 판단
- `예약` 이라는 말이나 시각이 없는 알림 → 저장조차 하지 않는다 (개인 대화 보호)
- 제목·날짜·시작시각이 같은 예약이 이미 있으면 → `duplicate` (일정 두 개 안 생김)

---

## 3. 새 형식 시험해보기 (dry-run)

일정을 만들지 않고 **어떻게 읽히는지만** 확인한다. 새 예약 앱을 추가하기 전에 쓴다.

```bash
curl -X POST "https://<앱주소>/api/tasks/notify?secret=<비밀키>&dryrun=1" -H "Content-Type: text/plain" --data "네이버지도 머바르지 죽전2호점 8.22(토) 오후 5:00 예약이 확정되었습니다."
```

```json
{"ok":true,"status":"dryrun","parsed":{"rule":"naver-booking-v1","title":"머바르지 죽전2호점 예약","date":"2026-08-22","start":"17:00","end":"18:00"}}
```

---

## 4. 진단 — 안 될 때

들어온 요청은 카드 알림과 같은 표에 `source = 'booking'` 으로 남는다.

```sql
SELECT created_at, result, reason, left(raw_text, 100)
FROM notify_requests WHERE source = 'booking'
ORDER BY created_at DESC LIMIT 20;
```

| result | 뜻 | 조치 |
|---|---|---|
| `created` | 일정 등록됨 | 없음 |
| `duplicate` | 이미 있는 예약 | 없음 (정상) |
| `unparsed` | 형식을 못 읽음 | `raw_text` 를 보고 규칙 추가 |
| `ignored` | 예약 알림이 아니거나 광고 | 폰의 단어 조건 확인 |
| `unauthorized` | 비밀키 불일치 | URL 의 `secret` 확인 |
| **기록 자체가 없음** | **폰이 안 보냄** | MacroDroid 발동 조건·권한 확인 |
